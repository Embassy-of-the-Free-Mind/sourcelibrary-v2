## What Needs Doing: Color System Cleanup

The brand page is incomplete. The actual codebase uses a much richer (and somewhat inconsistent) color system that needs alignment.

### Current state: Two overlapping color systems

**1. CSS custom properties (globals.css) — the "design system":**
- `--accent-rust: #9e4a3a` — links, annotations, prose
- `--accent-gold: #c9a86c` — decorative, search highlight, logo flame
- `--accent-sage: #8b9a7d` — OCR/AI features
- `--accent-slate: #546b8a` — secondary accent
- `--accent-violet: #7c5db5` — AI assistant, explain features
- `--bg-cream: #fdfcf9`, `--bg-warm: #f5f0e8`, `--bg-dark: #1a1612`
- `--text-primary: #1a1612`, `--text-secondary: #444`, `--text-muted: #6b6560`
- `--border-light: #e8e4dc`, `--border-medium: #d4cfc4`

**2. Raw Tailwind colors — used directly in components:**
- `amber-*` (50-800) — CTAs, buttons, focus states, loading spinners
- `blue-*` — experiment variant A, forms, data
- `purple-*` — experiment variant B, annotations, AI
- `green-*` — success states
- `red-*` — errors, deletions
- `yellow-*` — warnings, pending
- `stone-*` — neutral/structural (full scale)
- Plus `rose-*`, `teal-*`, `emerald-*`, `sky-*` in scattered spots

### Problems to address

1. **Amber vs Gold mismatch**: Amber-600 (#d97706) is used for buttons/CTAs, but `--accent-gold` (#c9a86c) is a different muted gold used decoratively. Are these meant to be the same accent? They look different.

2. **Dark color inconsistency**: `--bg-dark` is `#1a1612` (warm brown-black) but the logo/brand page uses `#1a1a1a` (neutral dark). The homepage hero overlay also uses pure `black`. Pick one.

3. **Processing pipeline has 12 unique color pairs** (hex values in `/api/admin/processing-dashboard`) that don't map to any design tokens.

4. **Annotation types each have hardcoded Tailwind colors** (blue-100 for context, purple-100 for reference, etc.) — not referenced to design tokens.

5. **Semantic colors (success/error/warning) use raw Tailwind** rather than design tokens. This is fine for a component library but makes the brand page incomplete.

### Decisions needed from Derek

1. **Which colors are "brand" vs "UI utility"?** The five accent tokens (rust, gold, sage, slate, violet) feel intentional. The Tailwind colors feel like UI utility. Should the brand page show both?

2. **Amber vs Gold**: Consolidate to one warm accent, or keep both (amber for actions, gold for decoration)?

3. **Dark background**: Standardize on `#1a1a1a` (current logo) or `#1a1612` (current CSS token)?

4. **Gradient backgrounds**: The warm cream gradients (`#f6f3ee` → `#f3ede6`) are a signature look. Include in brand guidelines?

5. **Scope**: Should the brand page be a full design system reference (colors + typography + spacing + components), or just logos + core palette?
