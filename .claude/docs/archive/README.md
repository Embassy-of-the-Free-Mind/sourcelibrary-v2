# Archived docs — snapshots, not doctrine

Everything in this directory was **true when it was written** and is now archaeology.
These are one-off audits and point-in-time investigations: a dedup run, a cover-image
sweep, a cross-reference of one collection against another on one particular day.

**Do not cite anything here as current.** Counts, schemas, and file paths in these
documents describe the repo as it was on the date in the filename. If you need to know
how something works *now*, the living docs are one level up in `.claude/docs/`.

They are kept, not deleted, because they are provenance — they record why a decision was
made and what the data looked like at the time. Archiving them just stops them competing
for attention with docs that describe the present.

## The convention

- **A date in the filename means snapshot.** `bph-dedupe-2026-05-12.md` belongs here.
- **Undated docs are living.** They describe the system as it is, and must be updated —
  or archived under their final date — when that stops being true.
- Finish a one-off investigation → date it, put it here directly.
- A living doc goes stale → archive it under its last-accurate date rather than leaving
  it to rot in place, where it will be trusted.
