# Greek Classical Texts Acquisition List

Target: Match the scope of the Loeb Classical Library's Greek half (~280 volumes, ~70 authors).

**Current state:** ~71 confirmed Greek books + 9 Greek/Latin bilingual. Strong in Neoplatonism (Plotinus, Proclus, Iamblichus, Porphyry). Weak in mainstream classical canon.

**Key resource:** The [Loebolus project](https://ryanfb.xyz/loebolus) has collected ~277 public domain Loeb volumes as downloadable PDFs. Internet Archive also hosts a [Teubner Edition Collection](https://archive.org/details/Teubner-Edition-Collection) with 146 Greek-only critical texts.

## Tier 3: Neoplatonic / Esoteric (~45 volumes)

**Already partially covered in Source Library.**

### Plotinus (7 vols)

MacKenna translation (1917-1930) -- first volumes PD. Thomas Taylor translations (1787-1834) fully PD on IA. Armstrong Loeb (1966-1988) NOT PD.

### Philo of Alexandria (12 vols)

Yonge's 4-volume translation (1854-55) covers most of Philo -- PD on IA. Colson/Whitaker Loeb (1929+) borderline PD.

### Iamblichus (NOT in Loeb)

Thomas Taylor translations: De Mysteriis (1821), Life of Pythagoras (1818) -- PD on IA. Modern: Clarke/Dillon/Hershbell (2003) not PD.

### Proclus (NOT in Loeb)

Dodds' Elements of Theology (1933) on IA. Thomas Taylor translated extensively (all PD). No Loeb edition.

### Porphyry

Thomas Taylor On Abstinence (1823) PD on IA. Limited Loeb coverage.

### Hermetica (NOT in standard Loeb)

G.R.S. Mead "Thrice Greatest Hermes" (1906, 3 vols) PD on IA. Everard "The Divine Pymander" (1650) PD. Copenhaver (1992) not PD.

### Apostolic Fathers (2 vols)

Lake (Loeb, 1912-13) PD on IA. Lightfoot (1891) PD.

### Early Greek Philosophy (9 vols)

Laks/Most (Loeb, 2016) NOT PD. Burnet's Early Greek Philosophy (1892) is the classic PD alternative.

## Import Strategy

### Option A: Loeb bilingual editions from IA
- **Pros:** Greek + English already on facing pages, translations are scholarly, PD pre-1929
- **Cons:** OCR will intermingle Greek and English on each spread; split detection needed for facing-page layout; our OCR pipeline would need to handle bilingual pages
- **Best for:** Quick wins where we want both text and translation immediately

### Option B: Greek-only critical editions (Teubner/OCT) from IA
- **Pros:** Clean Greek text for OCR, no competing English; best scholarly texts
- **Cons:** Need AI translation from scratch (our strength); no pre-existing English on page
- **Best for:** Highest quality Greek OCR + fresh AI translations

### Option C: Import both
- Import Loeb bilingual for the facing-page reading experience
- Import Teubner/OCT Greek-only for clean OCR source text
- Cross-reference translations

### Recommended approach
Start with **Option A** (Loeb bilingual) for Tier 1 authors -- Homer, the tragedians, Thucydides, Herodotus. These have clean standalone IA identifiers ready to import. Then layer in Teubner Greek-only editions for OCR quality validation.

### Greek OCR considerations
- Polytonic Greek (accents, breathing marks, iota subscript) is harder than Latin OCR
- Teubner editions use consistent typography -- good for OCR training
- Need to validate Gemini's Greek OCR quality on sample pages before bulk import
- Consider a Greek-specific OCR prompt (like we have for Latin and German)
