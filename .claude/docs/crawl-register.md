# Crawl register: every bulk crawl of the library we know about

PRIOR ART: .claude/docs/invariants/crawler-access-gate.md — holds the LESSONS and the controls, one bullet per incident, but no single list of the crawls themselves. This is that list; the invariant doc stays the place for rules.

**Names stay out of this file.** The repo is public, so rows identify a crawl by network and behaviour. Attribution of people and institutions lives in the private ops repo, `security/scraper-fleet-ledger.md`, which carries the same crawls with names.

**Read this when:** a crawl is found, a crawl protection is added or removed, or someone asks "has this happened before?". Add a row the same day a crawl is found. Figures are as measured at the time; the issue holds the evidence.

**Why it exists:** on 2026-10-10 Derek asked which crawls had happened and whether they could happen again, and the answer was spread across a 60-bullet invariant doc, six issues and a bill review. Every row below was found late, and most were found by accident.

## What stops the next one (as of 2026-10-22)

1. **Crawl brake** (Cloudflare `http_ratelimit` rule): more than 60 full `/book/` page loads a minute from one address gets a managed challenge for 10 minutes. Excludes `_rsc=` requests (a real browser's in-app navigation) and verified bots. Tested 2026-10-10: requests 1–60 answered, request 61 challenged. Every crawl in the table above exceeded this rate. Our Pro plan cannot exempt by user agent in rate-limit rules.
2. **Hosting-network challenge** (Cloudflare custom rule, 2026-10-11): reader pages (`/book/`) from OVH, Google Cloud, Azure, DigitalOcean, Linode, Vultr, Contabo, M247, Leaseweb and Datacamp get a managed challenge. Rented servers do not read books; a person on a VPN passes. Deliberately not AWS (our Vercel functions), not Hetzner (our job boxes), not `/api/` (paying API customers); verified bots and invited agents bypass via the skip rules.
3. **Detector** (`scripts/workers/edge-crawl-alert.mjs`, hourly at :07 on Hetzner): reads Cloudflare, which sees clients our own analytics cannot, and pushes ntfy when one address reads more than 1,500 book pages an hour, or one user agent on one network more than 2,000. Catches crawls that stay under the brake by spreading out.
4. **Canary** (`edge-crawl-alert.mjs --canary`, weekly): proves the brake still challenges and the detector can still see traffic; pages ntfy if either fails. A protection that stops working looks exactly like a quiet week.
5. **Client-hint rule** (Cloudflare custom rule `cb7dfe4b`, block, 2026-10-22, #4476): on `/book*`, `/work*`, `/api/pages*` and `/api/image*`, it blocks three things. (a) A desktop Chrome UA that sends no `sec-ch-ua` header; real Chrome has sent one on every HTTPS request since version 89. (b) A `sec-ch-ua-platform` value without quotes. (c) DigitalOcean with a Chromium-only brand list. None of these depends on a version number, so a pool that rotates its UA does not escape them, which per-version rules could not achieve (144 → 147 → 149 inside nine days). Its block page explains the usual innocent cause, a UA switcher or privacy extension, and asks wrongly blocked readers to write to team@sourcelibrary.org. The home page and `/developers` stay reachable. Hints are recorded on pageviews (`analytics_pageviews.ch_ua`, #7054) and API calls (`api_usage.ch_ua`, #7124), so the next forgery can be measured the same way.
6. **Attack canary** (`scripts/workers/attack-canary.mjs`, weekly on Hetzner, Mon 06:43): about 24 requests. It plays every scraper trick above that we block and every kind of visitor that must get through (real Chrome with hints, Firefox, Safari, Android, our own scripts), on sourcelibrary.org, the tenant subdomains and the hosts outside the zone. It pages ntfy when any answer changes. This catches a defence that quietly stops working, and a rule that starts refusing readers.
7. **Cloudflare ruleset size**: the Pro plan allows 20 custom rules. On 2026-10-22 the ruleset was consolidated from 20 to 17. The Lightpanda and Greek-crawler UA blocks were folded into the named-scraper rule `e227add6`, and the ClaudeBot block, disabled since 07-05, was deleted (its expression is above in `invariants/crawler-access-gate.md`). Prefer rules keyed on behaviour (client hints) over one rule per UA version.
8. **Vercel firewall, preview builds** (project-level rule "Preview builds: no anonymous book content", 2026-10-22, #7155). Every build keeps a permanent URL running its own frozen code, outside Cloudflare. On 2026-10-22 a census found about 530 preview and 3,500 production builds retained. Four long-lived aliases (staging, `episode-sources`, `bph-catalogue-updates`, `playpowerlabs`) and every pre-August build served a whole book's text to anyone. The rule denies anonymous book content (`/book`, `/work`, `/embed`, the text, page, image, dataset, MCP and search APIs) on any PREVIEW deployment, whatever its age. A session cookie or Authorization header passes, so branch review still works. It checks only that the cookie exists, so it stops fleets, not a scraper aiming at us. Production is deliberately excluded: production calls itself through its own `VERCEL_URL` without credentials (cache warming, pipeline steps, imports). **Still open:** old *production* builds from before about 2026-08-09, and the `playpowerlabs` alias that points at one of them. Their fix is deleting old builds, a decision for Derek on #7155.
9. **Existing layers**: Cloudflare custom rules (blocks and challenges), app-layer network blocks (`src/lib/blocked-networks.ts`, `blocked-asn-prefixes.json`), the tripwire link (`/catalog/complete`, since 2026-10-06), `traffic-anomaly-alert` (JavaScript-running clients only), `r2-egress-spike-alert` (direct bucket pulls). Rules and lessons for all of these: `invariants/crawler-access-gate.md`.

**Known gap:** a fleet that spreads below 60 pages a minute per address AND below the detector's hourly limits across many addresses. That is the wide-shallow walker case; `wide_shallow_walker` in `traffic-anomaly-alert` watches it for JavaScript-running clients only.
