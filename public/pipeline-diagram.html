Hetzner (cax31 ARM)
root@46.224.122.120
pipeline-orchestrator.mjs*/2 min
All phases — fallback orchestrator. Per-phase crons also run independently.
translate-worker.mjs*/2 min
Inline translation via Gemini. 20 concurrent books, 8K pages/run cap.
BPH → gemini-3-flash-preview | Others → gemini-3.1-flash-lite-preview
batch-collector.mjs*/10 min
Polls Gemini Batch API, writes OCR results to pages.
archive-ocr.mjs*/30 min
Per-page IIIF download → Cloudflare R2. Rate-limited per domain.
archive-bulk.mjs*/10 min
IA bulk JP2 zip download → R2. 4x faster than IIIF.
sync-worker.mjs*/2 hr
Reconcile book counters (pages_ocr, pages_translated, pages_archived) from page data.
resize-worker.mjs*/30 min
Generate display-size images from full-res on R2.
pipeline-health-alert.mjs7:00 UTC
Daily throughput + storage alerts.
AWS Lambda
eu-central-1
ocr-processorSQS standard
Preview OCR only (first 25 pages). 10 reserved concurrency.
translation-processorSQS FIFO
Preview translation + manual jobs only. Production uses Hetzner.
image-extraction-processorSQS standard
All image extraction (Phase 8). 10 reserved concurrency.
write-processorSQS batched
All Lambda → MongoDB writes. 50 reserved concurrency. Prevents connection storms.
