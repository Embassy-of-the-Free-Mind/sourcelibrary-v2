Upgrade Pipeline

The automated upgrade script checks sources in this order:

  1. Wikidata → alternate Commons images — same artwork may have multiple uploads, some much larger
  2. Rijksmuseum API — 93K pre-1700 prints, all CC0 at high resolution
  3. Met API — 375K public domain works, direct image URLs
  4. Art Institute of Chicago — IIIF, often highest resolution available
  5. National Gallery of Art — IIIF, US public domain

Running the upgrade

# Dry run first
set -a; source .env.production.local; set +a
node scripts/upgrade-lowres-artworks.mjs --dry-run --limit 20

# Live run (downloads, uploads to R2, updates DB, unhides)
node scripts/upgrade-lowres-artworks.mjs --limit 50

Adding a new museum source

To add a new museum API to the upgrade pipeline:

  1. Add a searchMuseum(title, artist) function that returns { source, imageUrl, objectUrl, objectNumber, title, artist, license }
  2. Add it to the fallback chain in main()
  3. Ensure the license is CC0 or CC-BY compatible
