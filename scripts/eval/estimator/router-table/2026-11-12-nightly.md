# Router table lane-judge (#6740, #8283)

Generated by `build.py` from `rules.json` and `scripts/eval/estimator/router-table/defect-rates.json`. Opus is the judge, reading each output against the page image. ● = the route the router assigns now.

**The rule** (#8283): severity-weighted defects per 1,000 words against the live route (bar: `current.json` → `2026-11-01-validated-7263`; an unrated live route has no privilege, the best rated route is the bar). Rated = >= 10 books of verdicts tied to the text judged. Gate 1: wrong text <= the bar's + 0.15 per 1,000 words (no text served: P(wrong text <= 1.0) >= 0.9). Gate 2, the floor: P(acc >= acc_live - 0.05) >= 0.5, paired where judged on the same pages. Pick: lowest price per raw page + $0.01 x words/1000 x (misleads + 3 x wrong text), labels deflated by the re-check (misleads x 0.625, wrong text x 0.8); a pick that moves across $0.001-$0.1 is HOLD. Fees: default plan fee (rules.json fees, the v2 / #7417 convention); dollars are not committed. Opus lanes: sonnet-read@1: no lane: scripts/eval/sonnet-router-7263/test.mjs (sealed claude -p --model sonnet, live OCR prompt); sonnet-img@1: correct.mjs --model=sonnet --per-call=1; opus-img@10: correct.mjs (--per-call, default 10); opus-img@1: one page a call (paddle-correct-6561 / tibetan-correct-6560 harness); opus-text: claude-translate.mjs (--per-call=10).

**Around it.** *Hard floor*: a route is blocked when P(invented or wrong-leaf rate > 0.02) >= 0.9, with at least 1 such page seen. *Menu* (#8283): an undecided cell takes the plainest agy route that passes the floor, never the incumbent. *Judge validity* (V2): below. A person's `planned` decision and a `held` cell stand.

**Page size** (inbox 2026-10-26, Derek: "10 pages are not the same in all books"). A Claude page costs k x (overhead / pages per call + the page's own tokens), tokens weighted input + 5 x output; page sizes per cell from `scripts/eval/estimator/router-table/page-sizes-2026-10-26.json`. Overhead 16,150 weighted tokens a call; k central per kind of call correct 5.60e-07, translate 1.76e-07, range [1.76e-07, 5.60e-07]. **The Claude weekly quota is not published per token: this is an estimate.**

**Not split by script type** (no by-script file; their pages enter the `/unknown` cells only until scripts/eval/router-next-7263/ evidence_pages.py, classify-evidence.mjs and split_evidence.py are rerun): `scripts/eval/estimator/router-table/evidence/confidence-validation-7866.score.json`, `scripts/eval/estimator/router-table/evidence/en-pre1800-gpu-6871.score.json`, `scripts/eval/estimator/router-table/evidence/lane-accept-7263.score.json`, `scripts/eval/route-judge-6740/results/router-tests-diffqa-2026-10-28/confirm-frame/score.json`, `scripts/eval/route-judge-6740/results/router-tests-diffqa-2026-10-28/router-frame/score.json`.

**'-written' rows are scored over the pages drawn** (#8111): a page the route refused counts as not accepted, so acceptance and the cost per accepted page are over the pages tried. Each '-written' evidence entry carries `written_of_drawn` (rules.json, or the score file); refused, with none: `scripts/eval/estimator/router-table/evidence/by-script/lane-judge-sampler.score.json latin-blank pero>agy-flash-low-written`.
