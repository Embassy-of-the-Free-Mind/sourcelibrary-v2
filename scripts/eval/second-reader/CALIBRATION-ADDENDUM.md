## Addendum for this packet (reader calibration)

This packet is not a fortnightly run. Differences from the brief above:

- **Each book has ONE page**, not a run of three. Judge the page on its own. Fill the per-book fields from that page
  and the `structure` counts, and keep them short.
- **The image is already on disk.** Each page has `image_file`, a path relative to this folder. Open it with the Read
  tool. Do not download anything and do not open any URL. Ignore step 2's `curl` instruction above.
- **Work only inside this folder.** Read nothing outside it: no other packet, no earlier result, no repository file.
  Everything you need is here.
- **Add two fields to each page object**, both answered from the IMAGE, never from the transcription:
  - `printed_marker`: the printed page number, folio, signature or catchword you can see on the leaf, quoted exactly
    as printed (e.g. `"127"`, `"fol. 12v"`, `"B3"`), or `"none visible"`.
  - `layout`: one short phrase on what the leaf looks like: columns, marginal notes, an illustration, ornaments, a
    table (e.g. `"two columns, notes in the outer margin"`).
- Quote the transcription and the translation exactly when you name an error, so the quote can be found in the text.
