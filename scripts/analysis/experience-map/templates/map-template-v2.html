Traditions transmit different things

The clearest structure is not which states get described but how. Some reach us almost entirely as instruction — a method for producing the state — and others almost entirely as testimony. The split falls along tradition lines, and is visible in the map as the contemplative region sitting apart from the visionary mass.

What brought it on

Historical sources almost always say what preceded the state — a fast, a fever, a drug, a vigil, a bereavement, a drum. Modern experimental phenomenology cannot ask this question, because it holds the cause fixed by design. This is the axis the historical record has and the laboratory does not.
