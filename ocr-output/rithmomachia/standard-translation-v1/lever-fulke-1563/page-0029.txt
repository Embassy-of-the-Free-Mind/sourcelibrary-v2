This page illustrates the specific numerical values assigned to the triangular game pieces in the Philosophers' Game (Rythmomachia). It categorizes the pieces based on their "superparticular" ratios, which are derived from a base number plus a fraction of itself. The first set of triangles (representing the white side) uses ratios like one and a half and one and a fourth based on odd numbers (3, 5, 7, 9). The second set (representing the black side) uses ratios like one and a third and one and a fifth based on even numbers (4, 6, 8, 10). The tables display the resulting numbers that would appear on the physical game pieces.
