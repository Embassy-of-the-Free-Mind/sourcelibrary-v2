<summary>
This page provides a reference table for the mathematical game Rithmomachia (The Philosopher's Game). It details the specific numerical combinations required to capture an opponent's piece using the rules of multiplication and division. A capture occurs when the value of a player's piece, multiplied by the number of empty spaces between it and an opponent's piece, equals the value of that opponent's piece. The table is organized into sections for "Even against Odd" and "Odd against Even" interactions.
</summary>
