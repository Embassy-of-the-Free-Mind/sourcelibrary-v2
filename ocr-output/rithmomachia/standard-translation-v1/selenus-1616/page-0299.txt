# On the Game of Chess.

[[notes: Squares h4 or f4]] / to take the **Black King’s Knight** [[notes: *Reuter* (rider) refers to the Knight.]] / with the **King’s Knight** / and to move the **King’s Bishop’s Soldier** / to thirty-five [[notes: Square c5]] &c.) / moves [the pawn] to the **White King’s Bishop** / on nineteen [[notes: Square c3]] : then **the White player** / must not / [take] with the **Queen** / the exposed / **Black King’s Bishop** / (for otherwise He / would be immediately **Check-Mated** / by the [Black] **Queen** / from twelve [[notes: Square d2]]) / but rather / with the **King’s Knight’s Soldier** [[notes: King's Knight's pawn.]] / take the **Black King’s Bishop’s Soldier** / and move it / onto the aforementioned **Black Bishop** : **the Black player** / takes / it / with the same / and moves / to the **White King’s Rook** : **the White player** / [moves] the same / against him / to three [[notes: Square c1]] : **the Black player** / [moves] the same / to thirty-three [[notes: Square a5]] : **the White player** / [moves] the **King’s Bishop** / (to prevent / the **Black King’s Rook** / from being moved to five [[notes: Square e1]] / and subsequently / to forty-four [[notes: Square d6]]) / to twenty-seven [[notes: Square c4]] : **the Black player** / (because He / [regarding] the **King’s Bishop’s Soldier** / intending / to trap the **White King’s Bishop** / subsequently / does not wish to defend with their **Rook** / on sixty-two [[notes: Square f8]]) / [moves] against the same / the **King’s Knight’s Soldier** / to thirty-four [[notes: Square b5]] : **the White player** / takes / with the same / the **Black King’s Bishop’s Soldier** / and moves / it / to their [Black's] **Rook** : **the Black player** / [moves] the same / against him / to sixty-two [[notes: Square f8]] ;
