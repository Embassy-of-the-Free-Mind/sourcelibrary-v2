# Of the Game of Chess.
[[note: "Vom Schach-Spiel" is the standard title for this section of the manual.]]

<margin>5. cap:</margin>
[...to protect] the same / by the King’s **Rook** [[note: "Rochen," an archaic term for the Rook, derived from the Persian 'rukh']]) / the King’s **Rider-Soldiers** [[note: "Reuters-Soldaten," referring to the Knight's Pawns]] / to forty-seven [[note: Square g6]]: **The White** / [moves] the King’s **Rook** / to the **Black** King’s **Rook’s** [square] / at four [[note: Square d1]]: **The Black** / must / take it / with the same: ( For otherwise the **White** / with the King’s **Rider** [[note: "Reuter," the Knight]] / at thirty-six [[note: Square d5]] / would offer check / and move the same / onto the King’s **Rook**: If he then takes / the **White** King’s **Rider** / with the King’s **Rook** / it would be exchanged / for ten [[note: In early chess treatises, pieces were often assigned point values; a Knight was typically valued at 10 units]]) **The White** / [takes] the same / with the King: **The Black** / moves / the King’s **Rook** / (so that he does not lose the same / in check / from the **White** King’s **Rider** / at thirty-six) / to fifty-two [[note: Square d7]]: **The White** / takes / the **Black** King’s **Soldier** [[note: "Soldat," the Pawn]] / not with the King’s **Rider** / ( For otherwise / the **Black** / would move / the King’s **Archer** [[note: "Schütze," the Bishop]] / onto the **White** King’s **Rook** / at twenty-three [[note: Square g3]] / and offer a discovered check [[note: "Ab-Schach"]] / from his King’s **Rook** / and would thus obtain the same ) / but rather with the King’s **Rook**: **The Black** / [takes] the **White** King’s **Rook’s Soldier** / with the King’s **Archer** / and offers / from the King’s **Rook** / a discovered check: **The White** / moves / the King / to eleven [[note: Square c2]]: **The Black** / [moves] the King’s **Rook’s Soldier** / (in order to move the King / if it is necessary / to forty-nine [[note: Square a7]] / and to entrench [[note: "verschantzen," to move into a fortified or safe position]] the same) / to forty-one [[note: Square a6]]: Thus his game is better / arranged / than that of the **White** / and he will / if he takes care / surely win against him.

<margin>33.</margin>
But if the **White** / does not take / the **Black Rider** / (number 28.) / but instead / moves the King’s **Rider** / (for the protection / of the King’s **Soldiers**) / to nineteen [[note: Square c3]]: then the **Black** takes / with the King’s **Rider** / the **White** King’s **Rider** / and offers check: **The White** / takes / the same / with the King’s **Rook**: **The Black** / moves / the King’s **Soldier** / to the **White** King’s **Soldier** / at thirty-eight [[note: Square f5]]: **The White** / takes it / with the same: **The Black** / offers / with the King’s **Rook** / at twenty / check: **The White** / moves / the King / to thirty-one [[note: Square g4]]: **The Black** / [moves] the King’s **Rook** / (out of danger) / to sixty [[note: Square d8]]: **The White** / offers / with the King’s **Rider** / from twenty-five [[note: Square a4]] / check: **The Black** / moves toward it / the King / to thirty-four [[note: Square b5]]: **The White** / (to protect it) / [moves] his **Soldier** / to eighteen [[note: Square b3]]: **The Black** / [moves] the King’s **Rook** / to twenty-eight [[note: Square d4]] / and offers check: **The White** / moves / the King / to forty [[note: Square h5]]: **The Black** / [moves] the King’s **Archer** / onto the **White** King’s **Rook’s Soldier** / at forty-four [[note: Square d6]]: **The White** / [moves] the King’s **Rider** / to the **Black** King’s **Rook’s** [square] / at ten [[note: Square b2]]:
