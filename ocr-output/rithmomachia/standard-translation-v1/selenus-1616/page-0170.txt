It must however / (8.) he who / from the other / has received an advantage / also use it well / and direct and set his thoughts / as much as possible / toward this / that he trades one stone / for another / with him / for so long until he / is certain that the advantage he took / will serve his benefit. For we see / that / when the camps of two Potentates [[notes: *Potentaten*, meaning powerful rulers or sovereign princes; the author frequently uses military metaphors for chess]] / clash together / and must fight with one another / and the one / over the other / has gained an advantage / the former / presses forward with the same / until it / strikes down the latter / and brings away / the glory of the conquered field-battle. He can also / for that reason / not be blamed at all. For that same player / who / after he has attained an advantage / in his game / has spared his sword / which he / with great glory / and honor / could have used proudly / and for his trouble / might have been crowned King / in the field / yet still loses the same / is rightly worthy of mockery.

In the same way / (9.) if the opponent / also attains an advantage / be it now / as small / as it will / in this game / and with the same / might perhaps win / then the other should / trade and exchange his stones / cautiously / so that he does not lose the game / nor in the least / ruin it / or bring it into disorder. For oftentimes / even when one / has an advantage / a game / is lost thereby. Therefore / one should / at all times / in the trading or exchanging of stones / (of which more will be thought / below / in the 4th Chapter of this book) take good heed: therefore bring the same / into no disorder / nor place oneself in danger.
