# RYTHMOMACHIA, THE GAME

[[notes: This table is a continuation of the player's reference guide. In the Renaissance, "Music" was studied as a branch of mathematics (part of the Quadrivium). A "Musical" progression is what we today call a **Harmonic progression**. A simple example used in the game is 3, 4, 6: the difference between 3 and 4 (which is 1) and the difference between 4 and 6 (which is 2) have the same ratio as the first and last numbers (3:6 is a 1:2 ratio).]]
