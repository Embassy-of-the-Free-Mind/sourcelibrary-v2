Ausser diesen dreyen / seynd noch viel guter Hütten: aber
ausz täglichem gebrauch / wird man dieselben / wol erfahren: So
lassen sich auch / die Hütten / (gleich dem gantzen Spiele) besser
durch den Augenschein lernen / dan ausz dem fürschreiben: Auch
sol mans nicht dahin verstehen / alsz ob die Züge / also eben / auf ein-
ander gezogen werden mögen / sondern / man kan wol / eine
andere ordnung / darein fürnehmen / und itzt hie / dan dort / einen
ziehen / bisz die Steine / endlich / gleichwol also / wie angezeiget /
und wie sie / in der Hütte stehen sollen / geordnet werden: Es
