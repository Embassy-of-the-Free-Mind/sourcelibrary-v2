Diese itzt erzehlte Historie / hat auch / das *Chronicon Bavariæ, Andreæ Presbyteri, Ratispon: à Marq: Frehero, editum, pag: 17.* nebest Andern / fast gleiches Schlages / beschrieben.
Eine alte geschriebene Bayerische Chronick / meldet / von H. Albrecht / und H. Okarus / wie folget :
> Die zween Fürsten / hetten nit mer / dan einen Sun / ,,

Daß (8) ein Schachzieher / wan Er schon verlieret / keinen Schaden empfindet / dieweil das Spiel / ohne Jehnigen unkosten / und geld-Spildung / seiner Art nach / (davon droben / in der 3. Aigenschaft erinnert) sol verrichtet werden. Und / ob Er gleich / den kürtzern Ziehen / und dem Andern / den Lob des Sieges / überlassen muß / ihm selber / daß Er seine Steine / nicht besser geordnet / und inacht gehabt; nuhr zu zuschreiben hat / und kan deswegen / mit dem Andern / seinem Gegener / keinen Zanck / billig anfahen.

Es hat diese affecten, begierden oder bewegnußen des gemühtes / in zwoen Personen / (deren die eine / im spielen sehr sittsam / und ihre begierden / im Zaum zu halten gewust : die Andere aber / auf beeden seiten / denselben / den Zügel / gar schiessen lassen) *M. Giouanni Boccaccio*, (welcher im 1313 Jahre / nach Christi Geburt / gebohren / und im 1375 Jahre / cœlebs gestorben) *nel libro sesto, del suo Filocopo, carte 262*, für etwa dritte halb hundert Jahren / sehr artig abgebildet : dessen wort wir / dem Leser zur lust / zum beschluß / der beeden / itzt vorerzehleten nutzen / anhero setzen wollen :
