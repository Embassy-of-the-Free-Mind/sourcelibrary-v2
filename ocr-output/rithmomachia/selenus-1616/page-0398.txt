<header>Das Dritte Buch / 11. cap:</header>

<margin>II.</margin>
Soldemnach der Weisse / (wie Damianus zwar / n. 6. es dafür achtet) der S. K. Reuter / mit des K. Schützen / nicht nehmen / besondern / auf des Schwarzen anschläge / fleissige aufacht haben: und seine Königin / von dem orte / darauf sie stehet / hinter des K. Schützen (so fern Er des Sieges nicht wil überhoben seyn) hinweg ziehen. Summa / es spiele / der Schwarze / wie Er wolle / wan / der Weisse / in diesem Spiele / erfahren ist / so gewinnet Er dasselbe / viel leichter / wan Er / seines K. Schützen / umb der S. K. Reuter / nicht verwechszlet / besondern / mit seinen Reutern / herauß ins feld rucket / und seinen König / an einen sichern Ort / stellet: Der Schwarze / aber / wan Er sich folgendes / seiner Rochen / gebrauchen wil / wird gewislich leer stroh dreschen. Es gebe demnach der Weisse / (unangesehen / der Damianus, es für rahtsam / erachtet) nicht ursache / zur verwechszlung der Steine: Dan dem Schwarzen / (auf daß Er sich / umb so viel besser / auß des feindes anschlägen / wicklen möge) darnach zu streben / vielmehr wil obliegen.
