## Das Dritte Capittel.
### Von der Abtheilung dieser Kunst.

Was in gemein / von dieser Schach-Kunst / Natur und Wesen / uhrSprung und Nahmen / zu wissen / nötig / wird / in vorigen Capitteln / zur genüge außgeführet seyn.

Wie man aber / zu derselben gelangen mag / auf was Art und weyse / dieselbe / ordentlich fürzutragen / und erlernet werde / ob es wol schwer scheinet / so wird uns doch / die Kunst selber / wan wir uns nuhr / daß sie unter die Zunft derer gehöre / so man Artes Operatrices nennet / auß dem vorigen ersten Cap : erinnern / solches an die hand geben.
