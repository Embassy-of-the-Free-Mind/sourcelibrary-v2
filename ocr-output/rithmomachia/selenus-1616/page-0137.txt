<margin>II. cap:</margin>
der Schützen- und Reuter- Soldaten: der Rochen- Soldaten aber /
beschützen nuhr ein feld / nemlich das dritte / der Reuter.
Wegen dieser der Schach-Steine / einlosierung / wird erstlich /
die Schach-Tabel / in zwey Heupt-quartier / getheilet: und das eine /
des Weissen: das ander des Schwartzen Königes / quartier / genennet.
Es begreiffet aber / (nach folgendem Abriss) ein jegliches quartier /
vier zwerch-linien / in sich: die eusserste / und erste / wird genandt / die
Haupt: die andere / der Soldaten: die dritte / des Weissen / oder
Schwartzen Königes / dritte: die vierte / derselben vierte linie: mit
welcher sich dan / eines iedern Königes gräntze / endet.
