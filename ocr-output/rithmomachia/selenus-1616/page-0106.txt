>> und leere feld / für den Ackerman : daß iſt zimlich / das der
>> Richter beſchirmet die arbeiter / und die beſeſſen gut / mit dem
>> rechten : und ſo er gant / zu der gelincken ſyten / ſo gant er /
>> auf das ſchwartz lere feld / für den Arzt / daß zimlich iſt : wen
>> von der kunſt wegen / ſo ſeind die Richter und die Arzt ſip-
>> theil : wiewol daß iſt / das ſie einen underſcheid / an dem ampt
>> haben / wen der Arzt / ſol haben die lieb / wider zu geſund-
>> heit bringen : der Richter / zu der einigkeit des friedes. Der
>> zu der gelincken hand / der da weiß iſt / der hant zwien auß-
>> genge / von ſeiner eigen ſtat / einen zu der rechten hand / auf
>> das weiß / und das feld / für den kaufman / umb die kauf-
>> leuthe oft rats bedürfen / und ihr krieg / werden durch ein
>> Richter geendet / und auftragen : den Andern gang / zu der
>> gelincken hand / auf das weiß und lere Veld / der rybalde und
>> ſpyler / wan die oft krieg und diebſtal begand / ſo ſollen ſie /
>> durch die Richter / gebuſſet / und gepinget werden : Es iſt ze
>> wiſſen / das die Alten alweg gend / von dem dritten qwa-
>> der oder Velde / auf das dryt Veld / allwegen zu behalten
>> ihr aigen ſtett / in der form / in der wiß : Iſt es ſchwartz / der
>> allwegen uff ſchwartz gen : iſt er weiß / das er uff weiß gee /
>> und allwegen / iber eck : bezeichnet die ſicherheit / die die Rich-
>> ter allwegen / in ihren fürgangen haben ſollen / wen driwy
>> Veld / bezeichnet driwy ding / die der Richter / mercken ſol :
>> Er ſol recht ſach ſchawen : gerecht rede geben : und ſach / nach
>> dem als ſey vurgeben ſint / nach dem rechten urtheilen / nim-
>> mer abgen von der gerechtigkeit. Es iſt ze wiſſen / das der
