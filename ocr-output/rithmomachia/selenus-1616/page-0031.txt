## Das Erste Buch /
# Der Beschreibung / des
# Schach-Spieles.
### Das Erste Capittel.
#### Von der Natur / Art und Eigenschaften /
##### der Schach-Kunst.

<margin>1. cap.</margin>
Es ist nichtes in dieser Welt / welches mit Raht / und Verstande / fürzunehmen ist / das nicht nohtwendig / zur Kunst / gezogen werden müsse. Dan die geschwechete Natur / vermag / ohne gewisse Ordnung / Gesetze / Regeln / Masse oder Weyse / nicht / wie es wol / der Sachen notturft / erforderte / sich hierinnen zu erzeigen. Dannenhero / mit der Zeit / von den weysesten / und fürtreflichsten / die Künste erfunden / und von ihren Nachkommen / zur Vollenkommenheit / ferner gebracht worden : Welches dan / die gantze Philosophey / und daraus herfliessende allerhand Künste / gnugsam erweisen.

Diesem nach / werden wir / unserm Vorhaben / einen guten anfang machen / wan wir / von dem Schach-Spiele / gleichesfalles / daß es eine Kunst sey / setzen : weyl jah den beweiß / das Werck selbsten / verhoffentlich / mitbringen wird. Dan solches thut uns / erstlich / dieses Spieles Natur und Eigenschaft / folgendes / die Maß und Weyse / wie mans ordentlich fassen / lehren und lernen möge / an die Hand geben / und entdecken.
