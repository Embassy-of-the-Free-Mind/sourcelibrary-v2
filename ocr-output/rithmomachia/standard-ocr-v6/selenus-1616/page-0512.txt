Mit dem Abziehen / werden die Steine / alſo gewonnen / oder verſcherzet.

Wan Zween Steine / eines hauffens / in ſolche felder / auß welchen ſie / auf einen Stein / von des Gegeners hauffen / treffen können / gezogen werden: und wan des einen Zahle / von des andern Zahlen / abgezogen werden / dieſelbe Zahle / mit welchen / des gedachten Gegeners Stein / gezeichnet / zu wege bringen / ſo wird derſelbe zwar genommen: ſie verbleiben aber / auf den feldern / dahin ſie / für daſmahl gezogen worden: Alß / wan der Weiſſe Viereckete / mit 15. auf F: und der Weiſſe Runde Stein / mit 6. auf G: und der Schwarze Runde / mit 9. verzeichnet / auf H, gezogen worden: ſo kan deßwegen / (dieweyl 6. von 15. genommen / 9. überlaſſen) und dieſe beede Weiſſe Steine / den Schwartzen / erreichen können) der Schwartze Runde Stein / mit 9. verzeichnet / vom Spiele / füglich wol genommen werden.

Folgende Zahle / gewinnen / und werden gewonnen / auf dieſem Spiele / mit dem Abziehen: und ſeynd auf der lincken ſeiten / die Weiſſe und Schwartze Zahlen / welche man / untereins ander abziehet / und einen Schwartzen / oder Weiſſen Stein / rauben: auf der rechten hand aber / die Zahle / welche auf dem Weiſſen / oder Schwartzen Stein / welcher geraubet wird / gefunden werden / geſetzet.
