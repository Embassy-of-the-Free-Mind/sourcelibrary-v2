Mit dem Zusammen-rechnen / werden die Steine / wie folget / genommen oder verloren:

Zween Steine / mit geringern Zahlen / können einen / mit höhern Zahlen / so ferne ihre zusammen-gerechnete Zahle / mit des andern Zahlen / übereinstimmen / und sie / in solche felder / auß welchen sie / ihrem gange gemäß / in das feld / darinnen der mit den höhern Zahlen / vorhanden / reichen und treffen können / gezogen werden / erlangen und gewinnen : Sie aber / verbleiben auf ihren feldern : Als / wann der Weisse Runde Stein / mit 16, auf C: und der Weisse Dreyeckete / mit 9, auf D: und der Schwartze Runde Stein / mit 25, verzeichnet / auf E, stünde : so wird dieser Schwartze Stein / dieweyl / der beeden Weissen Steinen Zahle / 25, machen / und an den ort / in welchem / der Schwartze / stehet gelangen können / auß E, hinweggenommen : sie aber verbleiben / auf C und D.

Folgende Zahle / gewinnen / und werden erobert / in diesem Spiele / mit dem Zusammen-zehlen : Und stehen / auf der lincken seiten / die zwo Zahlen / des Weissen hauffens / welche einen Schwartzen ; oder des Schwartzen / welche einen Weissen Stein / erlegen können : Auf der rechten hand aber / die Zahle / des Steines / welcher / wegen der beeden itzgedachten Zahlen / kan genommen werden.
