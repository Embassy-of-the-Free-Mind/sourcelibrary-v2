6.) Wan zwischen einem Steine / und dem felde / in welches derselbe / dem Spiele gemäß / wol könte gezogen werden / ein Stein / auß seinem / oder des Gegentheiles Hauffen / vorhanden / so kan er / dahin / nicht gezogen werden.

7.) Die Türne / werden / auf so vielerley Art / gezogen / nehmen auch andere Steine / und werden von ihnen genommen / als Viereckete / Dreyeckete / und runde Steine / auf denselben verhanden. Ferner / seynd sie / mit dieser freyheit begabet / daß sie ihre Steine / welche ihnen sollen genommen werden / durch andere Steine / ihres Hauffens / oder welche sie vom Feinde / erlanget haben / auf welche / dieselben Zahle / stehen / welche auf dem Steine / den sie verlieren solten / gezeichnet seynd / hinwieder an sich wechseln und bringen können. Wan aber kein Stein / darauf dergleichen Zahle / zu finden / bey ihnen vorhanden / so stehet es / in des überwinders willkür / einen Stein / welchen Er wil / hinwegzunehmen. Wan aber / die unterste Staffel / oder der grund-Stein / und also die Summe aller Summen der Staflen / nemlich 91, und 190, sol genommen werden / so kan man denselben / nicht außwechseln / noch von newen / und zum andernmahl hinwider / auf die Tafel setzen: sondern / muß ihn gantz auß dem Spiele wegschaffen: gleich wie auch die andere Staflen / wan man an ihre stelle / keine andere Steine / weggeben kan / weggethan werden.
