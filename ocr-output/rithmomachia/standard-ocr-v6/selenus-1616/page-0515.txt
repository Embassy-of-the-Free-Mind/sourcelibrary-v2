Nachdem nuhn / die fünferley weyse / wie man die Steine /
sol wegnehmen: (nemlich das Zahlen / Zusammenrechnen / Abziehen /
Vermehren und Theilen / welche in der Zahl-Kunst zwar gezeiget /
aber durch dieses Spiel / in der gedechtnuß vielfaltig geübet werden)
erkläret seynd: alß folget ferner / die sechste und letzte Art / nemlich
das Einsperren / und geschicht folgender gestalt.

Wan ein Stein / von des Gegentheiles Steinen / also umbge-
ben ist / daß er / durch seinen / ihm gebürenden gang / nicht kan vort-
gerucket / noch / durch seines Hauffens andere Steine / dieweyl Sie
keinen / von den vier Steinen / welche demselben zusetzen / und den
Paß verlegen / wegraumen können / entsetzet werden: so wird er /
wie belagert / und eingesperret / geachtet / und vom Spiele / auß-
gemustert: Zum Exempel: Wan ein Weisser <term>Dreyecketer</term> / auf
L. und vier Schwartze Steine / auf M. N. O. P. stehen: alß ist der
gedachte Dreyeckete / so fern ihm keiner / auß seinem Hauffen / zu
hülfe kommet / bestricket und gefangen. Bey dieser sechsten Art /
ist zu behalten / daß alle Steine / auf diesem Spiele / belagern / und
belagert oder umbringet werden können: alleine der Weisse <term>Vier-
eckete</term> Stein / mit 153. und der Schwartze Viereckete Stein / oder
die unterste Staffel / des Schwartzen <term>Turnes</term> / mit 190 beschrieben /
werden nuhn durchs einsperren verloren / oder erlanget. cc
