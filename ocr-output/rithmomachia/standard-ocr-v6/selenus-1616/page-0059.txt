Hieher gehöret auch das Spiel / so man *πόλεις* genennet : das
von *Cratin* : in *fugit* : und *Plato lib : 4. de Rep:* gedencket : Wie
auch droben / im ersten Cap: auß dem *Erasm : Roterod :* albereit er-

und eben das Spiel ist / welches mit unserm Schach- oder vielmehr
Streit-Spiele / übereinstimmet.

Ferner ist ein Spiel gewesen / welches man *Ludum quinque
Linearum*, oder eigentlich *πεττείαν*, quasi *πεντείαν*. (wiewol dieses
wörtlein / auf alle andere / dieser Art Spiele / vom *Hesychio*, und
Andern / die vorige *allusion* hindangesetzet / nicht unbillig / gezo-
gen wird) genennet : davon man / beym *Polluce, d. lib :* und *Simone
Majolo, Episc: Vulturariense*, in seinen *Diebus Canicularibus, pag:*
576. S. *πεσσοί*. lesen mag.
