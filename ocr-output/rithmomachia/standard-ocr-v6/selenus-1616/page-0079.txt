<header>Vom Schach-Spiel.</header>
<margin>4. cap:</margin>

Obersten und Führern / viel besser können erkennet / und wie sie / genaturet seynd / abgemercket werden.

Findet man derowegen / bey Jeglichen Theile / sechszehen Steine : welche / wie Sie / in zween hauffen / von ein ander abgesondert / also an der zahle der Steine / gleich / und nuhr an farben / unterschieden seynd.

Achte derselben / heisset man / die Haupt-Steine / und werden / wie folget / genennet :

Diese Acht fürnehmste Steine / wan man auf dieses Spieles Zweck / zielen wil : können folgender gestalt / hinwider unterschieden werden : Als / in den General Feld-Herren / bey welchem alles gelegen / und umb dessen willen / die Andere Steine / sich / zu diesem Kriege / begeben : nemlich den König : In den Feld-Marschalck / als / die Königin : In die Obersten und Befehlshabere / als / die Rochen : In die Reuterey / als / die Reuter : In die Doppel Soldner / als / die Schützen : Dan Sie billicher / als / die Spiesse-träger / (wie *Johan : Jacobi von Wallhausen / in seiner Krieges-Kunst zu Fuss / pag : 59.* nicht ohne ursachen / wider den ungrischen gebrauch / vermeynet) des doppelten Soldes würdig.

Die übrigen Acht Steine / welche in der audern Zwerch-linie / und nechsten feldern / für den obangedeuteten Haupt-Steinen / stehen / werden / in diesem *Tractat*, die Soldaten / durch welche / das Fussvolck angedeutet wird / genennet.

*Fr. Jacobus de Casallis, (in Tractatu de Moribus Hominum & Officio Nobilium)* Imgleichen / *Jacobus Publicius Florent : (in suo de Oratore & Artificiali Memoriâ, libro)* theilen diese Steine / in sondersbahre Empter / und geben ihnen dahero / folgende unterschiedene Mahmen.

Diese wollen / wie es scheinet / das *Schach-Spiel* / auf ein gantz Regiement / dessen Stände und Empter / ziehen. Ob es nuhn wol dahin / eigentlich nicht gerichtet / so seynd wir doch vorhabens / zu des Lesers lust und wolgefallen / an seinem Orte / weitleuffigere erinnerung / ins künfftige / hievon zuthun.
