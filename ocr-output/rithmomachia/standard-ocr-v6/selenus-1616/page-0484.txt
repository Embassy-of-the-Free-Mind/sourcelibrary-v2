<header>Das Erste Capittel / 1.cap:</header>

Die Tafel / welche zu diesem Spiele / gebrauchet wird / stimmet / wegen der weissen und schwartzen Felder / in welche Sie / ebenmessig unterschieden / mit dem Schach-Brete / überein.

Ihre form oder gestalt / anbelangend: ist Sie / noch einmahl so lang / als Sie breit ist / und wird / die Länge derselben / in sechszehen - die Breite aber / in acht felder / (gleich als / wan zwey Schach-Breter / zusamen gefüget wehren) abgetheilet.
