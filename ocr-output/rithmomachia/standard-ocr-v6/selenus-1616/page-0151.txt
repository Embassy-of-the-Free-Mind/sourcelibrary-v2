ihm Schach gibt / entdecket / ſo heiſſet mans einen **Ab-Schach.**
Wan aber der weggeruckte Stein / zween Steine / auf den König /
dergeſtalt entblöſſet / (wie ein Exempel / im dritten Buche / cap : 4. n.
16. zu finden) ſo heiſſet mans / einen doppelten **Ab-Schach.** Nuhn
kan man zum öftern / durch dieſes **Ab-Schachen** / einen guten Stein /
wan man auf denſelben / den abgerucketen Stein ziehet / ertappen.
Dan man / nachdem des Andern König / auß dem Schache zu ziehen /
getrungen wird / im folgenden zuge / den guten Stein / welcher / im
vorgehenden zuge / iſt gefangen worden / ohne einigen widerſtand / kan
erlangen. Wan aber mit dem Steine / welcher gerucket worden /
und den **Ab-Schach** / vom andern Steine / zu wege gebracht / zu gleich
auch Schach gegeben wird / ſo neñet mans einen **Doppelten Schach/**
oder **Schach und Ab-Schach.** Es wird aber / durch alle Steine /
jah auch durch den König ſelber / (außgenommen die Königin) aber
nicht von allen / der **Ab-Schach** / gegeben. Von der Königin geſchicht
Er / durch einen Soldaten / wan derſelbe / auf der nächſten linie / für
ſich / zur rechten / oder lincken hand / einen andern Soldaten / oder
Stein erſchläget / und Ihr die linie / gegen des Andern König / frey
machet : Ebenmeſſig / kan ein Schütze / ein Reuter / ein Roche / jah
ihr König / derſelben / eine freye Straſſe / zu des Gegentheiles König /
ge/machen. Gleicher geſtalt / entblöſſet man auch einen Rochen / und
Schützen / umb dem Könige / des Andern hauffens / von Ihm / Schach
zu geben. Vom Reuter aber / weyl ſich derſelbe / weder auf- noch be-
decken läſſet / wird dergleichen **Ab-Schach** / nicht gegeben.
