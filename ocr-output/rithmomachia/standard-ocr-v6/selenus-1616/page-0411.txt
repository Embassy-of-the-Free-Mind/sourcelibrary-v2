# Das Vierte Buch /
# Der Beschreibung / des Schach-Spieles.
### Das Erste Capittel.
### Von der Ersten Art zu spielen / wan einer / nuhr einen Vortheil genommen / und nicht außgegeben hat.

<image-desc>A large decorative historiated initial 'E' featuring scrolling vines and floral motifs.</image-desc>

Es sey nuhn genug / von den gewöhnlichen / und beeden Spielern / gleichen Arten / und weysen / zu spielen : Folgen itzo / die sonderbahre : wan nemlich / ein Spieler / dem andern / einen Vortheil gibt / oder von demselben nimt. Es werden aber / derselben / für andern sechse / so wol nach des Authoris, alß des Damiani, anleitung / (doch diese / mit gründlicher und volliger verbesserung) in folgenden acht Capitteln / fürgestellet / und mit denselben / der Bericht / von dem kleinen Currier-Spiel / geschlossen.

Die Erste Art / belangend : so entstehet dieselbe / wan Einer / unter den Spielern / (zum Exempel / der Weisse / ) nuhr einen Vortheil / alß etwa zween Züge / im anfange des Spieles / zu gebrauchen : genommen und bekommen.
