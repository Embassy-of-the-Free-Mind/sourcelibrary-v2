<header>Vom Schach-Spiel.</header>

<margin>II. cap:</margin> übrigen sieben weissen / und sieben schwartzen Haupt-Steinen / verstehen.

Diese Quartier / wan man sie hinwider an ein ander setzet / werden ferner / in acht gerade / auffsteigende linien / getheilet : deren die erste / der Königes-Rochen : die andere / der Königes-Reuter : die dritte / der Königes-Schützen : die vierte / der Königes : die fünfte / der Königinne : die sechste / der Königinne-Schützen : die siebende / der Königinne-Reuter : die achte / der Königinne-Rochen linie / genennet wird.

Ob nuhn wol / diese Abtheilunge der Schach-Tafel / in die unterschiedene quartier / linien und felder / denjenigen / welche dieses Spiel / außwendig / (das ist / im Sinne) Spielen wolten / dienen möchten / so seynd sie doch / für dieselben nicht gnugsam. Dan sie müssen / nebest einer guten gedächtnus / langem gebrauch und übung / entweder auf eines jeden Haupt-quartieres / oder auf des ganzen platzes felder zähle / auch achtung geben.

Was die zahle der Felder / in eines jeden Haupt-Quartier / antreffen / so muß man / von des Königes-Rochen / biß an den halben theil / der Schach-tabel / (nemlich ins vierte feld / der Königins-Rochens) die rechnung anfahen / auch in guter gedächtnus behalten / welches feld weiß / welches schwartz sey / und das folgender massen.
